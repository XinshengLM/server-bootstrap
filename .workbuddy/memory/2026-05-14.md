# 2026-05-14 记录

## 项目了解

### 项目名称
Server Bootstrap - Linux 服务器一键初始化工具包

### 项目结构
- `user-manager.sh` (1400+ 行): 用户与 SSH 管理
- `shared-workspace-setup.sh` (660+ 行): 共享工作区配置
- `package-install.sh` (1163+ 行): 常用软件一键安装

### 核心功能
1. **用户管理**: 创建/删除/锁定用户,SSH 密钥管理,sudo 权限配置
2. **SSH 安全加固**: 禁 root、禁密码登录、修改端口
3. **共享工作区**: `/home/workspace` 结构化管理,SGID + ACL 权限
4. **软件安装**: 15 个常用软件(含安全工具 Fail2Ban、UFW、Maldet、htop)

### 安全特性
- 原子写入(临时文件 + mv)
- 信号捕获 + 中断回滚
- 安全网检查(防止锁死)
- sudoers/sshd 语法验证
- 输入校验(正则表达式)

### 救急方案
- 非 root 诊断模式: 生成 VNC 恢复命令
- 云控制台 VNC: 最后恢复手段

### 推荐工作流
1. 软件安装
2. 创建用户(SSH 密钥 + NOPASSWD sudo)
3. SSH 安全加固
4. 安装 Fail2Ban
5. 设置共享工作区
